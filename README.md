# Calculation Tools Website

Welcome to **Calculation Tools Website** – a simple yet powerful web application designed to make everyday calculations effortless! Whether you need to perform basic arithmetic, check your BMI, convert currency, or calculate area, we've got you covered. 🚀

## 🌟 Features

### 🎨 Theme Support: Light & Dark Mode 🌞🌙
Switch between light and dark mode for a comfortable viewing experience.

### 🧮 Basic Arithmetic Operations
- Perform **Addition, Subtraction, Multiplication, and Division**.
- Simply enter two numbers, select the operation, and get instant results!

### ⚖️ BMI Calculator
- Enter your **height (cm)** and **weight (kg)** to calculate your **Body Mass Index (BMI)**.
- Get insights into your fitness category: *Underweight, Normal, Overweight, or Obesity*.

### 💱 Currency Converter
- Convert between **USD, EUR, and GBP** using fixed exchange rates.
- Enter an amount, select the source and target currencies, and get the converted value.

### ⚖️ Weight Converter
- Convert **kilograms (kg) to pounds (lbs)** and vice versa.
- Enter a value, select the units, and get an instant conversion!

### 📏 Size Calculator
- Calculate the **area of a rectangle** by entering its **length and width (cm)**.
- Click the "Calculate Area" button to see the result instantly.

---

## 🛠 How to Use

### **Basic Arithmetic Operations**
1. Enter two numbers in the input fields.
2. Select an operation (Add, Subtract, Multiply, Divide).
3. Click the **"Calculate"** button to get the result.

### **BMI Calculator**
1. Enter your height (cm) and weight (kg).
2. Click the **"Calculate BMI"** button.
3. View your BMI value and fitness category.

### **Currency Converter**
1. Enter the amount you want to convert.
2. Select the source and target currencies.
3. Click the **"Convert"** button to get the converted amount.

### **Weight Converter**
1. Enter the weight value.
2. Select the source and target units (kg or lbs).
3. Click the **"Convert"** button to see the converted weight.

### **Size Calculator**
1. Enter the length and width of a rectangle (cm).
2. Click the **"Calculate Area"** button.
3. The area will be displayed instantly!
