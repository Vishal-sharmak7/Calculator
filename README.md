Calculation Tools Website
This is a simple web application that provides various calculation tools, including Basic Arithmetic Operations (Add, Subtract, Multiply, Divide), BMI Calculation, Currency Converter, Weight Converter, and Size Calculation. The project is built using HTML, CSS, and JavaScript.

Features

Theme: Dark and light 👇☀️🌙

Basic Arithmetic Operations:

Perform addition, subtraction, multiplication, and division.

Input two numbers and select the operation to get the result.

BMI Calculator:

Calculate Body Mass Index (BMI) using height (in cm) and weight (in kg).

Displays BMI value and fitness category (Underweight, Normal weight, Overweight, Obesity).

Currency Converter:

Convert between USD, EUR, and GBP using fixed exchange rates.

Input an amount and select the source and target currencies.

Weight Converter:

Convert weight between kilograms (kg) and pounds (lbs).

Input a weight value and select the source and target units.

Size Calculation:

Calculate the area of a rectangle using length and width (in cm).

How to Use
Basic Arithmetic Operations:

Enter two numbers in the input fields.

Select the operation (Add, Subtract, Multiply, Divide).

Click the "Calculate" button to see the result.

BMI Calculator:

Enter your height in centimeters (cm) and weight in kilograms (kg).

Click the "Calculate BMI" button to see your BMI and fitness category.

Currency Converter:

Enter the amount you want to convert.

Select the source and target currencies.

Click the "Convert" button to see the converted amount.

Weight Converter:

Enter the weight value.

Select the source and target units (kg or lbs).

Click the "Convert" button to see the converted weight.

Size Calculation:

Enter the length and width in centimeters (cm).

Click the "Calculate Area" button to see the area of the rectangle.

Files in the Project
index.html:

The main HTML file containing the structure of the webpage.

Includes input fields, buttons, and result display areas for all tools.

styles.css:

The CSS file for styling the webpage.

Includes styles for headers, sections, input fields, buttons, and result displays.

script.js:

The JavaScript file containing the logic for all calculations.

Includes functions for arithmetic operations, BMI calculation, currency conversion, weight conversion, and size calculation.
